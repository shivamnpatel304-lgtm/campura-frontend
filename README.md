# Campura Website

React + Vite + Tailwind CSS website inspired by the supplied Campura reference.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Replace branding/assets

- Replace the `🌿` logo in `src/components/Header.jsx` with your real Campura SVG/PNG.
- Replace the CSS-built hero visual in `src/App.jsx` with a real product image when you have one.
- Replace the WhatsApp number, email and phone number with the real business details.
- Connect the contact form to Formspree, EmailJS, a backend API, or your preferred CRM before production.

The layout is intentionally responsive and uses real HTML/Tailwind components rather than making the entire page a screenshot.
